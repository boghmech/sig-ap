# ساخت APK
1. در github.com یک مخزن (repo) جدید بسازید.
2. همه فایل‌های این پوشه (از جمله پوشه .github) را در آن آپلود کنید.
3. تب Actions ← Build APK ← Run workflow. بعد از ~5 دقیقه، در پایین صفحه‌ی اجرا، فایل signal-app-apk (حاوی app-debug.apk) را دانلود کنید.
4. APK را روی گوشی نصب کنید (اجازه نصب از منبع ناشناس).
